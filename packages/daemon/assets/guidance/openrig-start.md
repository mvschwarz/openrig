# OpenRig Start

Run `rig whoami --json` first and again after compaction, restart, or restore.
Use its live identity and session addresses. If it omits peers, rerun with `--all-peers`.
A short or empty transcript can miss activity.

- `rig send <session> "message"` sends a message to a peer's terminal.
- `rig capture <session>` reads the peer's screen.
- `rig context get help` opens the help guide. If the CLI is down, see [OpenRig help](https://www.openrig.dev/help/agents) or `daemon/docs/reference/help.md` inside the installed `@openrig/cli` package.

Use your rig's onboarding to learn its purpose and your role.
Ask for orientation if your rig hasn't provided it.
